# TFG-Aurora-Adrian-Delgado
Repositorio del TFG: Estudio de la propagación de ondas acústicas en guías de onda: diseño de cavidades resonantes y cristales fonónicos (Grado en Ingeniería Física, UPV).

## Descripción del Proyecto
Este trabajo analiza la propagación de ondas acústicas en medios confinados, abordando el diseño, simulación numérica y validación experimental de cavidades resonantes y cristales fonónicos. Se han utilizado herramientas de análisis modal, aproximación de onda plana y matriz de transferencia para el estudio de la transmisión y confinamiento de energía acústica.

## Estructura del Repositorio
- `/memoria`: Versión final del documento PDF.
- `/presentacion`: Diapositivas utilizadas en la defensa pública.
- `/codigos`: Scripts en Python utilizados para el modelado numérico y procesado de datos experimentales.
- `/disenos_CAD`: Archivos .STEP/.STL utilizados para la fabricación mediante impresión 3D.
